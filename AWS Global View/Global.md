# AWS Global View

## Overview

The AWS Global View provides a centralized summary of resources deployed across all enabled AWS regions. It helps teams quickly understand the overall infrastructure footprint, including compute, storage, networking, and security resources.

### Key Highlights

* Resources distributed across **17 enabled AWS regions**
* Active compute and storage workloads deployed in a single region
* Networking infrastructure available across all enabled regions
* Security configurations managed through VPC networking controls and security groups

### Purpose

Use the Global View dashboard to:

* Monitor resource distribution across regions
* Identify deployed services and infrastructure components
* Review networking and security configurations
* Support operational, compliance, and infrastructure management activities
