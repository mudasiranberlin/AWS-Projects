# 🚀 Project 1: AWS Amplify + GitHub (CI/CD Deployment)

This project demonstrates how to deploy a static or web application using **AWS Amplify** with a **GitHub repository**. It enables a fully automated **CI/CD pipeline**, where every change pushed to GitHub is automatically deployed to the live website.

---

## 📌 Overview

AWS Amplify provides a simple way to host and deploy web applications directly from GitHub. Once connected, it automatically handles:

- Build process
- Deployment
- Hosting
- Continuous updates (CI/CD)

---

## 🔧 Deployment Steps

### 1. Open AWS Amplify Console
Go to the AWS Amplify service in the AWS Management Console.

### 2. Create a New App
Click on **Deploy an App**.

### 3. Connect GitHub Repository
- Authorize AWS Amplify to access your GitHub account
- Select your repository from the list
- Choose the branch you want to deploy (e.g., `main` or `master`)

### 4. Configure App Settings
- Review build settings (default settings usually work in most cases)
- Click **Next**

### 5. Review and Deploy
- Confirm all configurations
- Click **Deploy**

---

## 🌐 Access Your Website

After successful deployment:

- AWS Amplify will generate a **public domain URL**
- Copy and open the URL in your browser
- Your website will be live 🎉

---

## 🔄 CI/CD Workflow (Automatic Updates)

Once connected, the workflow becomes fully automated:

1. Make changes in your project locally
2. Push updates to GitHub
3. AWS Amplify detects the changes
4. Automatically builds the project
5. Deploys the updated version
6. Website updates instantly
