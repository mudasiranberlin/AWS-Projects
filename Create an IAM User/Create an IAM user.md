## Create an IAM User

## Overview

This project demonstrates the fundamentals of AWS Identity and Access Management (IAM) by creating and managing users, groups, permissions, and security controls following AWS best practices.

## Objectives

* Create an IAM user with AWS Console access
* Create an **Admins** group
* Attach the **AdministratorAccess** managed policy
* Add the IAM user to the Admins group
* Enable MFA for the root account
* Configure a secure IAM password policy

## Key Concepts

* IAM Users and Groups
* IAM Policies and Permissions
* Root User vs IAM Admin User
* Multi-Factor Authentication (MFA)
* Console and Programmatic Access
* AWS Security Best Practices

## Security Best Practices Applied

* Enabled MFA for the root account
* Used IAM users instead of the root user for daily tasks
* Implemented strong password requirements
* Managed permissions through groups and policies

## Skills Gained

* AWS Identity and Access Management (IAM)
* User and Group Administration
* Access Control and Security
* AWS Account Protection
