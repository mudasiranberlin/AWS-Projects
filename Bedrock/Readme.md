
## 🚀 Getting Started

### Prerequisites

- An AWS account with access to Amazon Bedrock
- Recommended region: **us-east-1** (N. Virginia)

### Quick Start

1. Create the three prompts in **Prompt Management**.
2. Build the flow in **Bedrock Flows**.
3. Test with sample emails.
