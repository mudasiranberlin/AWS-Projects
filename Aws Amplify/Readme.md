# AWS Amplify

## Overview

AWS Amplify is a set of tools and services that helps developers build, deploy, and host full-stack web and mobile applications quickly.

It works well with frontend frameworks like React, Angular, Vue, Next.js, and mobile apps.

---

# What is AWS Amplify?

AWS Amplify allows you to:

- Build web and mobile applications
- Connect to AWS backend services
- Host websites with continuous deployment
- Add user authentication
- Store files and data
- Build APIs
- Monitor application performance

---

# AWS Amplify Components

## 1. Amplify Hosting

Used to host websites and web applications.

Supports:
- React
- Angular
- Vue
- Next.js
- Gatsby
- Static HTML/CSS/JavaScript

Features:
- Global CDN
- HTTPS
- Custom domain
- Automatic deployments

---

## 2. Authentication

Add secure login to your application.

Supports:
- Email and password
- Phone number
- Google login
- Facebook login
- Apple login
- Amazon login

Powered by Amazon Cognito.

---

## 3. API

Connect your frontend with backend services.

Supports:
- REST API
- GraphQL API

---

## 4. Storage

Store files such as:

- Images
- Videos
- Documents
- Audio

Powered by Amazon S3.

---

## 5. Database

Store application data using:

- DynamoDB
- GraphQL with AppSync

---

## 6. Functions

Run backend code without managing servers.

Powered by AWS Lambda.

---

## How AWS Amplify Works

```
Developer
      │
      ▼
Build Application
      │
      ▼
Push Code to GitHub
      │
      ▼
AWS Amplify
      │
      ├── Build
      ├── Test
      ├── Deploy
      └── Host
      │
      ▼
Users Access the Website
```

# Simple Workflow

1. Create an application.
2. Connect your GitHub repository.
3. Amplify builds the project.
4. Deploy the application.
5. Users access the hosted website.
6. Every new Git push automatically updates the website.
